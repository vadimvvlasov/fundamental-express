## 3. Модель дисконтирования денежных потоков (DCF)

- Стоимость собственного капитала: Ke = Rf + β×ERP = 4% + 1.00×5% = 9.00%
- Стоимость долга после налога: Kd×(1-T) = 4.5%×(1-21%) = 3.55% (Kd=4.5% и T=21% — фиксированные допущения методики, не специфичны для компании и не эффективная налоговая ставка компании)
- Веса структуры капитала (по рыночной капитализации): E/(D+E) = 97.8%, D/(D+E) = 2.2%
- **WACC:** 97.8%×9.00% + 2.2%×3.55% = **8.88%**
- CAGR роста FCF: 4.26% (лог-регрессия по годам, ограничена 2-15%)
- Терминальный темп роста: 2.5%

- Долгосрочный долг (Long Term Debt, только процентный долг): 0.10 млрд. USD
- Денежные средства (Cash and Cash Equivalents): 0.33 млрд. USD
- Чистый долг, использован в DCF (расчёт: Долгосрочный долг − Кэш): -0.23 млрд. USD

> Допущение по лизингу: в базовом DCF обязательства по аренде исключены из net debt, поскольку модель использует FCF после операционных арендных платежей. Это упрощающее допущение, а не универсальный бухгалтерский факт (выплаты по финансовой аренде могут классифицироваться иначе) - для сопоставлений, где lease liabilities рассматриваются как debt-like obligations, используйте альтернативный расчёт с Total Debt (включая аренду) вместо приведённого net debt.
