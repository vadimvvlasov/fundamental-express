Данный документ является **исчерпывающим, самодостаточным техническим заданием** для разработки/модернизации консольной утилиты на Python 3.13+, выполняющей глубокий экспресс-анализ эмитентов акций на основе данных из **Yahoo Finance (`yfinance`)**. 

У кодинг-агента **нет доступа к лекциям и учебным материалам**, поэтому спецификация содержит все точные математические формулы, алгоритмы локации строк, структуры балансов и логические пороговые значения.

### 1.1 Архитектурные принципы
1. **Модульность по типам активов:** Отчетность обычных компаний, банков и трастов недвижимости (REIT) кардинально отличается. Скрипт должен динамически определять сектор/индустрию тикера и запускать соответствующий пайплайн:
   * **Ordinary Companies (Обычный сектор)** — классический чеклист грехов (двухуровневый) + DCF (WACC/CAPM) + Форвардные метрики.
   * **Banking Sector (Банковский сектор)** — специализированная структура баланса, чеклист банковских грехов + Dividend Discount Model (DDM) / P/B-ROE Valuation.
   * **REITs (Трасты недвижимости)** — метрики FFO/AFFO/NOI, специализированный чеклист REIT-грехов + Оценка по чистой стоимости активов (NAV через Cap Rate).
2. **Отраслевой предохранитель:** Запретить расчет некорректных метрик (например, `Current Ratio` для банков или обычный DCF для REIT) без явного флага `--force`. При его наличии — собирать отчет с обязательным выводом предупреждающего дисклеймера.
3. **Отказоустойчивость парсинга (`yfinance`):** Реализовать семантический поиск строк в таблицах `yfinance.financials`, `yfinance.balance_sheet` и `yfinance.cashflow` через многоуровневый алгоритм `find_row()` с приоритетом точного совпадения над частичным для избежания ложных срабатываний.
4. **Мультивалютный конвертер (Currency Bridge):** При несовпадении валюты отчетности (`info["financialCurrency"]`) и валюты торгов (`info["currency"]`) подтягивать курс через пару (например, `TWDUSD=X`) и конвертировать абсолютно все исторические денежные ряды перед расчетом справедливой стоимости. Ограничение: `EPS` остается в домашней валюте на одну акцию (без конвертации по курсу ADR, если применимо).
5. **PDF-Генерация (ReportLab):** Сгенерировать качественный одностраничный (или жестко контролируемый многостраничный) отчет в корпоративном стиле "Corporate Slate & Teal" с обязательным использованием шрифта `DejaVu Sans` для полноценной поддержки кириллицы.

## 2. МОДУЛЬ 1: ОБЫЧНЫЕ КОМПАНИИ (ORDINARY COMPANIES)

Используется по умолчанию для всех нефинансовых секторов (кроме REIT).

### 2.1 Двухуровневая модель чеклиста «грехов» (Scoring Model)
Чеклист отвечает на вопрос «стоит ли смотреть на компанию». Если сработает хотя бы один **Критический грех**, итоговый вердикт безоговорочно становится 🔴 **ПРОПУСТИТЬ (SKIP)**. Если критических грехов нет, вердикт выносится по взвешенной сумме баллов **Второстепенных грехов**.

#### 2.1.1 Критические грехи (Любой из них = 🔴 SKIP)
1. **Сжигание кэша (FCF ≤ 0):** Свободный денежный поток за последний TTM-период отрицательный или равен нулю.
2. **Угроза ликвидности (Current Ratio < 1.0):** Краткосрочные активы (`Total Current Assets`) меньше краткосрочных обязательств (`Total Current Liabilities`).
3. **Долгосрочная неплатежеспособность:** Долгосрочные активы за вычетом Гудвила меньше долгосрочных обязательств:
   $$\text{Non-Current Assets} - \text{Goodwill} < \text{Non-Current Liabilities}$$
   *(Если Goodwill отсутствует, вычитается 0)*.
4. **Отрицательный реальный капитал:** Собственный акционерный капитал равен или меньше нуля:
   $$\text{Shareholders Equity} \le 0$$

#### 2.1.2 Второстепенные грехи (Взвешенный балл)
Каждый сработавший триггер увеличивает балл на указанный вес. Сравнивается последний отчетный год с предыдущим (YoY).

| Вес | Триггер (Грех) | Условие проверки |
| :--- | :--- | :--- |
| **1.0** | **Падение капитала** | $Equity_{current} < Equity_{prior}$ |
| **1.0** | **Падение FCF** | $FCF_{current} < FCF_{prior}$ (при условии, что $FCF_{current} > 0$) |
| **1.0** | **Падение выручки** | $Revenue_{current} < Revenue_{prior}$ |
| **1.0** | **Падение операционной прибыли** | $OperatingIncome_{current} < OperatingIncome_{prior}$ |
| **1.0** | **Размытие акций (Dilution)** | Число акций в обращении выросло YoY более чем на **1.5%**:<br>$\frac{Shares_{current}}{Shares_{prior}} > 1.015$ |
| **0.5** | **Падение Current Ratio** | $CurrentRatio_{current} < CurrentRatio_{prior}$<br>**Только если** $CurrentRatio_{current} < 2.0$. *(Падение с 4.0 до 3.0 игнорируется)*. |
| **0.5** | **Падение Gross Margin** | $GrossMargin_{current} < GrossMargin_{prior}$ |
| **0.5** | **Падение Operating Margin** | $OperatingMargin_{current} < OperatingMargin_{prior}$ |
| **0.3** | **Падение чистой прибыли** | $NetIncome_{current} < NetIncome_{prior}$ |
| **0.3** | **Падение чистой маржи** | $NetMargin_{current} < NetMargin_{prior}$ |

*Специальный бонус:* Если компания проводит обратный выкуп акций (Buyback YoY сократился более чем на 1.5%), вычитать из итогового балла **-0.5 балла** (но итоговый балл не может быть ниже 0).

#### 2.1.3 Шкала вердикта (при 0 критических грехов):
* **Балл ≤ 1.0** $\rightarrow$ 🟢 **КУПИТЬ (BUY)**
* **Балл от 1.0 до 2.5** $\rightarrow$ 🟡 **НАБЛЮДАТЬ (WATCH)**
* **Балл > 2.5** $\rightarrow$ 🔴 **ПРОПУСТИТЬ (SKIP)**

### 2.2 Модель DCF (Discounted Cash Flow) справедливой стоимости

#### 2.2.1 Шаг 1: Темп роста FCF (CAGR)
Рассчитывается геометрический темп роста FCF за доступные 4 года:
$$\text{CAGR} = \left(\frac{FCF_{\text{last}}}{FCF_{\text{first}}}\right)^{\frac{1}{N}} - 1$$
* **Границы:** Темп роста жестко зажимается в диапазоне $[2\%, 15\%]$.
* **Дефолт:** Если исторический FCF на концах отрицательный или равен нулю, CAGR принимается равным **5.0%**.

#### 2.2.2 Шаг 2: Расчет ставки дисконтирования WACC (CAPM)
$$WACC = \left(\frac{E}{D+E} \times K_e\right) + \left(\frac{D}{D+E} \times K_d \times (1 - T)\right)$$

* **Стоимость собственного капитала ($K_e$):**
  $$K_e = R_f + (\beta \times ERP)$$
  * Безрисковая ставка ($R_f$) = **4.0%** (допущение).
  * Бета ($\beta$): Берется из `yfinance.info['beta']`. Если отсутствует, дефолт $\beta = 1.1$.
  * Премия за риск акций ($ERP$) = **5.0%** (допущение).
* **Стоимость долга ($K_d$):** Предельная стоимость долга до уплаты налогов $K_d = 4.5\%$ (фиксированное допущение).
* **Налоговая ставка ($T$):** Эффективная ставка налога $T = 21\%$ (фиксированное допущение).
* **Рыночные веса ($E$ и $D$):**
  * $E$ (Equity Value) = Рыночная капитализация (`yfinance.info['marketCap']`).
  * $D$ (Debt Value): Суммарный процентный долг (`Long Term Debt` + `Short Long Term Debt`). Если не найден — `Total Debt` (включая лизинг). Если оба пусты — $D = 0$.
  * *WACC жестко ограничивается в рамках $[5\%, 15\%]$.*

#### 2.2.3 Шаг 3: Прогнозирование FCF на 5 лет и Терминальная стоимость (Gordon Growth)
* Прогнозные FCF на годы 1-5 рассчитываются как: $FCF_t = FCF_{\text{last}} \times (1 + \text{CAGR})^t$.
* Каждый $FCF_t$ дисконтируется: $PV(FCF_t) = \frac{FCF_t}{(1 + WACC)^t}$.
* Терминальная стоимость ($TV$) рассчитывается по темпу терминального роста $g = 2.5\%$:
  $$TV = \frac{FCF_5 \times (1 + 0.025)}{WACC - 0.025}$$
  *Продисконтированная терминальная стоимость:* $PV(TV) = \frac{TV}{(1 + WACC)^5}$.

#### 2.2.4 Шаг 4: Расчет Enterprise Value (EV) и Справедливой цены
$$\text{Enterprise Value} = \sum_{t=1}^{5} PV(FCF_t) + PV(TV)$$
$$\text{Equity Value} = \text{Enterprise Value} - \text{Net Debt}$$
$$\text{Fair Value per Share} = \frac{\text{Equity Value}}{\text{Shares Outstanding}}$$

**Определение Net Debt для Equity Bridge (Шаг 6-7):**
* Предпочтительно брать готовый `Net Debt` от Yahoo Finance (где лизинговые обязательства ASC 842 уже исключены).
* Если поле пустое, рассчитать: `Total Debt` - `Cash and Cash Equivalents`. Лизинг исключать из расчета, так как арендные платежи уже вычтены из FCF.

## 3. МОДУЛЬ 2: БАНКОВСКИЙ СЕКТОР (BANKING SECTOR)

Банки зарабатывают на разнице процентных ставок (процентный доход) и комиссиях (непроцентный доход). Обычные показатели ликвидности (например, `Current Ratio`) и FCF для них бессмысленны.

### 3.1 Архитектурная специфика банковской отчетности
Кодинг-агент должен извлекать следующие банковские показатели:

#### 3.1.1 Balance Sheet (Баланс банка)
1. **Активы (Assets):**
   * `Cash and Cash Equivalents` (Ликвидный кэш) — должен быть оптимальным, излишек кэша YoY свидетельствует о неэффективности (деньги "не работают").
   * `Trading Assets` (Торговые активы) — ценные бумаги для спекуляций.
   * `Securities Held to Maturity / HTM` (Ценные бумаги до погашения) — преимущественно облигации, приносящие процентный доход.
   * `Net Loans` (Чистые выданные кредиты) — ключевой доходный актив. Должен разделяться на:
     * *Commercial Loans* (Кредиты бизнесу)
     * *Consumer Loans* (Потребительские кредиты)
     * *Mortgage Loans* (Ипотечные кредиты)
   * `Allowance for Credit Losses / Reserve for Bad Loans` (Резерв под кредитные убытки) — контрактив, уменьшающий портфель кредитов.
2. **Обязательства (Liabilities):**
   * `Deposits` (Депозиты) — ключевой источник фондирования:
     * *Demand Deposits* (Текущие счета без начисления процентов — самый дешевый источник).
     * *Time Deposits / Savings* (Процентные вклады).
   * `Short-term & Long-term Borrowings` (Заимствования от других банков / ЦБ).
   * `Derivatives & Trading Liabilities` (Обязательства по деривативам).
3. **Собственный капитал (Equity):**
   * `Preferred Stock` (Привилегированные акции), `Common Stock` (Обыкновенный капитал), `Retained Earnings` (Нераспределенная прибыль).

#### 3.1.2 Income Statement (Отчет о прибылях и убытках банка)
1. **Net Interest Income (NII - Чистый процентный доход):**
   $$\text{NII} = \text{Interest Income} - \text{Interest Expense}$$
   * *Interest Income* — доходы по выданным кредитам и ценным бумагам.
   * *Interest Expense* — расходы по выплатам на депозиты и привлеченным займам.
2. **Non-Interest Income (Непроцентный доход):**
   * `Fees and Commissions` (Комиссионный доход — стабильный поток от транзакций).
   * `Trading Revenue / Investment Banking` (Трейдинг и инвестбанкинг — волатильный доход).
3. **Credit Loss Provision (Резерв под кредитные убытки за период):**
   * Квази-себестоимость банка. Прямое списание части процентных доходов на ожидаемые потери.
4. **Non-Interest Expense (Непроцентные операционные расходы):**
   * Расходы на персонал (оклады банкиров, бонусы), ИТ-оборудование, маркетинг и аренду офисов.

---

### 3.2 Специализированный чеклист «грехов» для банков

#### 3.2.1 Критические банковские грехи (Любой из них = 🔴 SKIP)
1. **Процентный убыток:** Чистый процентный доход отрицательный или равен нулю ($\text{NII} \le 0$). Банк выдает кредиты под ставку ниже, чем привлекает депозиты.
2. **Отрицательный регуляторный капитал:** Акционерный капитал банка отрицательный ($\text{Shareholders Equity} \le 0$).

#### 3.2.2 Второстепенные банковские грехи (Взвешенный балл)

| Вес | Триггер (Грех) | Условие проверки |
| :--- | :--- | :--- |
| **1.0** | **Обвал чистой процентной маржи** | $NII_{current} < NII_{prior}$ |
| **1.0** | **Опасный рост резервов на потери** | $CreditLossProvision_{current} > 1.15 \times CreditLossProvision_{prior}$<br>*(Резерв под дефолты вырос более чем на 15% YoY)* |
| **1.0** | **Размытие капитала** | Рост числа акций YoY > 1.5% |
| **0.5** | **Дисбаланс соотношения Кредиты/Депозиты** | $LTD = \frac{\text{Net Loans}}{\text{Total Deposits}}$<br>**Триггер срабатывает, если:** $LTD > 100\%$ (опасная нехватка ликвидности) или $LTD < 60\%$ (избыточная ликвидность, банк работает пассивно). |
| **0.5** | **Накопление мертвого кэша** | $Cash_{current} > 1.30 \times Cash_{prior}$<br>**И одновременно** кредитный портфель упал: $Loans_{current} < Loans_{prior}$. *(Банк боится выдавать кредиты и копит обесценивающийся кэш)*. |
| **0.5** | **Рост операционных расходов** | Операционные расходы (Non-Interest Expense) растут быстрее, чем чистый операционный доход (NII + Fees/Commissions). |
| **0.3** | **Падение комиссионных доходов** | $Commissions_{current} < Commissions_{prior}$ |

*Шкала оценки вердикта аналогична классической (КУПИТЬ ≤ 1.0, НАБЛЮДАТЬ 1.0–2.5, ПРОПУСТИТЬ > 2.5).*

### 3.3 Модель оценки справедливой стоимости банков (DDM и ROE/PB)
Классический FCF не применим к банкам, так как изменение объема кредитов и депозитов интерпретируется формулой DCF как "движение капитала" и искажает результат. Применяются две альтернативные модели на выбор:

#### Вариант А: Модель дисконтирования дивидендов (DDM - Dividend Discount Model)
Применяется для стабильно платящих дивиденды банков.
$$\text{Fair Value} = \sum_{t=1}^{5} \frac{\text{DPS}_t}{(1 + K_e)^t} + \frac{\text{DPS}_5 \times (1 + g)}{(K_e - g) \times (1 + K_e)^5}$$
* $\text{DPS}_t$ — прогнозируемый дивиденд на акцию с историческим темпом роста дивидендов.
* $K_e$ — стоимость акционерного капитала, рассчитанная через CAPM (Шаг 2).
* $g$ — терминальный рост дивидендов (фиксирован на уровне **2.5%**).

#### Вариант Б: Модель рентабельности собственного капитала (ROE / PB Valuation)
Для банков, у которых дивиденды отсутствуют или нестабильны.
$$\text{Fair Value} = \text{Book Value per Share} \times \frac{\text{ROE}}{K_e}$$
* $\text{Book Value per Share}$ (Балансовая стоимость на акцию) = $\frac{\text{Shareholders Equity}}{\text{Shares Outstanding}}$.
* $\text{ROE}$ (Рентабельность капитала) = $\frac{\text{Net Income}}{\text{Shareholders Equity}}$ (за последний год).
* $K_e$ — требуемая доходность по CAPM.

## 4. МОДУЛЬ 3: ТРАСТЫ НЕДВИЖИМОСТИ (REITs - EQUITY REITs)

REIT владеют физическими объектами недвижимости и сдают их в аренду. В бухгалтерском учете здания амортизируются (списываются в расход), хотя в реальности их рыночная стоимость растет. Это занижает чистую прибыль (`Net Income`) и делает стандартные мультипликаторы (например, P/E) некорректными.

### 4.1 Специфические метрики REIT
Скрипт должен рассчитывать и выводить три ключевых REIT-индикатора вместо чистой прибыли:

1. **FFO (Funds From Operations - Средства от операций):**
   $$\text{FFO} = \text{Net Income} + \text{Depreciation \& Amortization} - \text{Gain on Sale of Real Estate}$$
   *Мы возвращаем амортизацию недвижимости обратно в доход и убираем разовые бумажные доходы от продаж зданий.*
2. **AFFO (Adjusted Funds From Operations - Скорректированные средства от операций):**
   $$\text{AFFO} = \text{FFO} - \text{Recurring Capital Expenditures (CapEx)}$$
   *Вычитаются обязательные капитальные расходы на регулярный ремонт и поддержание зданий (сантехника, крыши, отделка).*
3. **NOI (Net Operating Income - Чистый операционный доход от аренды):**
   $$\text{NOI} = \text{Rental Revenue} - \text{Property Operating Expenses} - \text{Real Estate Taxes}$$

---

### 4.2 Специализированный чеклист «грехов» для REIT

#### 4.2.1 Критические REIT-грехи (Любой из них = 🔴 SKIP)
1. **Опасный дивидендный payout по AFFO:**
   $$\text{AFFO Payout Ratio} = \frac{\text{Dividends per Share}}{\text{AFFO per Share}} > 100\%$$
   *(Если коэффициент > 100%, значит траст платит дивиденды "в долг", разрушая стоимость капитала).*
2. **Низкая заполняемость (Occupancy Rate < 80%):** Менее 80% площадей сдано арендаторам. Недвижимость простаивает, принося только издержки по налогам и ЖКХ.
3. **Отрицательный реальный капитал:** $\text{Shareholders Equity} \le 0$.

#### 4.2.2 Второстепенные REIT-грехи (Взвешенный балл)

| Вес | Триггер (Грех) | Условие проверки |
| :--- | :--- | :--- |
| **1.0** | **Падение AFFO** | $AFFO_{current} < AFFO_{prior}$ |
| **1.0** | **Снижение заполняемости объектов** | $Occupancy_{current} < Occupancy_{prior}$ |
| **1.0** | **Размытие капитала через SPO** | Рост числа акций YoY > **2.5%** *(REIT часто доэмитируют акции для покупки новых объектов, но сильное размытие снижает доходность инвестора)*. |
| **0.5** | **Критическая закредитованность по капиталу** | $DebtToEquity = \frac{\text{Total Debt}}{\text{Shareholders Equity}} > 200\%$ |
| **0.5** | **Падение NOI** | $NOI_{current} < NOI_{prior}$ |
| **0.3** | **Увеличение доли Капитальных Затрат** | $\frac{CapEx}{FFO}$ выросла более чем на 5% YoY. |

*Шкала оценки вердикта аналогична классической (КУПИТЬ ≤ 1.0, НАБЛЮДАТЬ 1.0–2.5, ПРОПУСТИТЬ > 2.5).*

---

### 4.3 Оценка справедливой стоимости REIT по чистой стоимости активов (NAV через Cap Rate)
Оценка производится на основе стоимости лежащей на балансе физической недвижимости, очищенной от долгов.

#### Шаг 1: Карта Ставки Капитализации (Cap Rate)
Ставка капитализации (процент доходности недвижимости) извлекается из `yfinance.info` (при наличии) либо определяется по географии и типу активов в Google-поиске. В случае отсутствия данных используется консервативная медиана в зависимости от специализации REIT:
* **Industrial / Logistics** (Склады) $\rightarrow$ **5.5%**
* **Residential** (Жилье, Apartments) $\rightarrow$ **6.0%**
* **Healthcare / Medical Centers** (Больницы) $\rightarrow$ **6.5%**
* **Office / Retail** (Торговые центры, офисы) $\rightarrow$ **7.0%**

#### Шаг 2: Расчет стоимости недвижимости (Property Value)
$$\text{Property Value} = \frac{\text{NOI}}{\text{Cap Rate}}$$

#### Шаг 3: Расчет Чистых Активов (NAV - Net Asset Value)
К стоимости недвижимости прибавляются ликвидные финансовые активы и вычитаются все обязательства:
$$\text{NAV} = \text{Property Value} + \text{Cash} + \text{Receivables} + \text{Construction In Progress} - \text{Total Liabilities}$$

#### Шаг 4: Расчет Справедливой стоимости на акцию
$$\text{Fair Value per Share} = \frac{\text{NAV}}{\text{Shares Outstanding}}$$

При написании кода кодинг-агент обязан строго следовать следующим правилам обработки данных и верстки отчета.

### 5.1 Алгоритм локации строк в `yfinance` (find_row)
Для исключения багов с перепутыванием строк (например, захват `Reconciled Cost Of Revenue` вместо `Total Revenue` при поиске по ключу `revenue`) использовать двухэтапный поиск:
```python
def find_row(df, keywords, default_val=0.0):
    # Шаг 1: Поиск точного совпадения (регистронезависимо) по всем ключевым словам
    for kw in keywords:
        for idx in df.index:
            if kw.lower() == str(idx).lower():
                return df.loc[idx]
                
    # Шаг 2: Поиск частичного совпадения (регистронезависимо)
    for kw in keywords:
        for idx in df.index:
            if kw.lower() in str(idx).lower():
                return df.loc[idx]
                
    # Шаг 3: Возврат дефолтной нулевой серии
    return pd.Series([default_val] * len(df.columns), index=df.columns)
```
